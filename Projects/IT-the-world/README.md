# IT: The World We Built — A Global Digital Civilization Exhibition

> **“One World. Three Horizons. An Engineered Reality.”**

![IT: The World We Built](https://images.unsplash.com/photo-1451187580459-43490279c0fa?q=80&w=1200&auto=format&fit=crop)

**IT: The World We Built** is a premium, modern, professional digital exhibition exploring the global Information Technology architecture powering human civilization. The project is structured across three cohesive atmospheric experiences unified under a sophisticated violet, wine, and lavender visual design system.

## 🏛️ Key Interactive Features

### 1. Unified Glass Navigation Bar
- Top-level persistent translucent glass header with backdrop blur (`blur(18px)`).
- **3-Page Chromatic Pill**: Shows the user's active page with glowing dot indicators.
- Quick in-page anchor links and responsive mobile navigation drawer.

### 2. 3D Visual Depth Language
- **Subtle Tilt Physics**: Cards subtly angle (`perspective(1000px) rotateX(...) rotateY(...)`) following cursor movement on non-touch screens.
- **Glassmorphic Panels 2.0**: Frosted glass surfaces with subtle border reflections and radial ambient glows.
- **Zero Gimmicks**: No spinning 3D cubes or generic templates. Depth is achieved strictly through sophisticated lighting, multi-plane elevations, and layered gradients.

### 3. Interactive IT Infrastructure Builder (Page 1)
- Located in `index.html` (powered by `js/builder.js`).
- Interactive topology canvas where users can toggle:
  - Hyperscale Cloud Data Centers
  - Subsea Optical Fiber Corridors
  - Distributed Edge CDN Cache
  - Tensor AI Neural Clusters
  - Zero-Trust Cryptographic Gateway
  - LEO Orbital Satellite Mesh
- Real-time animated data packet routing and live telemetry meters (Latency, Throughput, Uptime, Node Count).

### 4. Interactive Society Outage Simulator (Page 2)
- Located in `without-it.html` (powered by `js/simulation.js`).
- Users can simulate critical sector blackouts:
  - Banking & Financial Clearing (SWIFT, Cards, ATMs)
  - Electrical Power & SCADA Grids
  - Global Logistics & Air Traffic Control
  - Hospital Diagnostic Telemetry
  - Global Telecommunications & Satellites
- Dynamically computes the **Civilizational Breakdown Index (0% to 100%)**, estimated daily economic damage, and emits real-time crisis ticker alerts.

### 5. Interactive Quantum Superposition Lab (Page 3)
- Located in `beyond-it.html` (powered by `js/future.js`).
- Interactive probability slider allowing users to manipulate the state equation:
  $$\vert\psi\rangle = \alpha\vert0\rangle + \beta\vert1\rangle$$
- Real-time Bloch-style vector rendering on HTML5 Canvas comparing a deterministic binary bit against an exponential quantum qubit.
- Expandable **Horizon Roadmap (2027 to 2050+)** detailing post-silicon breakthroughs.
